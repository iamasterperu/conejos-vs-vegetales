# Conejos vs Vegetales 🐰🥕

Juego de defensa del huerto: los conejos soldados protegen la granja de los vegetales infectados. Una bola de alambre de púas cuida cada fila.

**Jugar:** https://iamasterperu.github.io/conejos-vs-vegetales/

## Instalar como app (pantalla completa)

**iPhone (Safari):** abre el enlace → botón Compartir → *Añadir a pantalla de inicio*. Abre el juego desde el ícono y gira el teléfono en horizontal.

**Android (Chrome):** abre el enlace → menú ⋮ → *Instalar app* (o *Añadir a pantalla de inicio*).

**PC:** botón ⛶ abajo a la derecha, o tecla **F**.

## Cómo se juega
Toca las zanahorias que caen, elige un conejo en la barra superior y colócalo en el huerto. Aguanta las oleadas y derrota al Rey Zapallo.
